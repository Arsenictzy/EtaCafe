# ==============================================================================
# PANDUAN INISIALISASI & SETUP PROYEK ETACAFE (FULLSTACK)
# Untuk Frontend & Backend Developer
# ==============================================================================

Halo! File ini berisi panduan lengkap langkah demi langkah untuk menjalankan backend,
menghubungkan database PostgreSQL, serta menjalankan frontend agar bisa langsung lanjut develop.

------------------------------------------------------------------------------
A. STRUKTUR & KEBUTUHAN UTAMA
------------------------------------------------------------------------------
1. Python (versi 3.10 / 3.11 disarankan)
2. PostgreSQL (sudah running di port 5432)
3. Node.js / Bun (untuk frontend)

------------------------------------------------------------------------------
B. LANGKAH INISIALISASI DATABASE & BACKEND (PYTHON FASTAPI)
------------------------------------------------------------------------------
1. Buka terminal dan masuk ke folder `backend`:
   cd backend

2. Buat Virtual Environment (jika belum ada):
   # Windows:
   python -m venv venv

3. Aktifkan Virtual Environment (Venv):
   # Windows (PowerShell):
   .\venv\Scripts\Activate.ps1
   # Atau jika menggunakan Command Prompt (CMD):
   .\venv\Scripts\activate.bat
   # macOS / Linux:
   source venv/bin/activate

   (Jika muncul error Execution Policy di PowerShell, jalankan PowerShell as Admin lalu:
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser)

4. Install seluruh dependensi backend:
   pip install -r requirements.txt

5. Konfigurasi file `.env` di dalam folder `backend/`:
   Pastikan ada file `backend/.env` (bisa copy dari `backend/.env.example`).
   Sesuaikan `DATABASE_URL` dengan password postgres masing-masing:

   DATABASE_URL=postgresql+psycopg2://<USER_POSTGRES>:<PASSWORD_POSTGRES>@localhost:5432/EtaCafe_db


6. Buat Database Kosong di PostgreSQL:
   - Buka DBeaver atau pgAdmin.
   - Buat database baru bernama: EtaCafe_db

7. Eksekusi Script Inisialisasi Database (Auto-Migrate + Seed Data):
   Jalankan perintah ini di dalam folder `backend` dengan venv aktif:
   python init_db.py

   -> Script ini akan otomatis membuat tabel:
      - users
      - categories
      - menu_items
      - promos
      - orders
      - order_items
   -> Serta mengisi data awal (kategori, menu, promo, dan 4 akun role).

8. Menjalankan Backend Server:
   uvicorn app.main:app --reload --port 8000

   - API Documentation (Swagger UI): http://localhost:8000/docs
   - API Alternatif (ReDoc): http://localhost:8000/redoc
